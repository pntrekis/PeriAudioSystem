# PeriAudio

A lightweight reusable FMOD audio framework for Unity.

## Requirements

- Unity 6+
- FMOD for Unity

FMOD must be installed separately.

## Features

- 2D and 3D one-shot playback
- Persistent and attached audio instances
- Music playback and switching
- Music parameters
- Global FMOD parameters
- Smooth parameter transitions
- Master, Music, SFX and Ambience bus control
- Optional automatic scene music

## Setup

1. Install FMOD for Unity.
2. Install PeriAudio.
3. Create an Audio Settings asset.
4. Add `AudioManager` to a GameObject.
5. Assign the Audio Settings asset.
